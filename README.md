# Mini Games Website

## Описание
Сайт с мини-играми, где пользователи могут провести время, играя в простые и увлекательные игры прямо в браузере.

## Технологии
- HTML  
- CSS  
- JavaScript 

## Функционал
- Набор мини-игр в одном месте  
- Простой и понятный интерфейс  
- Адаптивный дизайн
